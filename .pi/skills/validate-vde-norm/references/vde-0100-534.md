# DIN VDE 0100-534 — Protection against electric shock (touch voltage)

German adoption of IEC 60364-4-41. Governs **indirect protection**: if a fault
brings live parts to touchable surfaces, the protective device must disconnect
the circuit fast enough that the touch voltage stays below the safe limit.

## 1. The core requirement (§530)

For every circuit, the product of protective-conductor impedance and fault
current must satisfy:

```
Z_s · I_a ≤ U_T          (touch voltage limit)
```

- `U_T` — maximum permissible touch voltage, **50 V AC / 120 V DC** (dry
  conditions) for the general case; lower in wet/damp locations.
- `I_a` — current that causes the protective device to operate within the
  required time.
- `Z_s` — total impedance of the fault loop (phase + PE path).

In practice this is ensured by **RCDs (FI-Schutzschalter)** and/or short
fault-loop impedance, not by computing `Z_s` in a planning tool.

## 2. RCD (FI) requirements — what matters for PV systems

### Where an RCD is required
- **All socket-outlet circuits** (Steckdosen) in dwellings: RCD ≤ 30 mA.
- **Wallbox (EV charging):** RCD Type B, ≤ 30 mA is mandatory for AC EV
  charging circuits (DC fault currents from the vehicle's PV/battery must be
  detected → **Type B**, not just Type A). SolarPlanner's `Wallboxes` inventory
  should therefore carry a flag for the required RCD type.
- **PV inverter AC feed-in:** an RCD is NOT universally required at the
  coupling device (Kuppelstelle) for grid feed-in — but many installers and
  some grid operators require one (300 mA, Type A or F) for additional safety.
  Treat as **recommended / check local grid operator rules**, not a hard VDE
  requirement for the inverter itself.

### RCD classes (Tabelle / §532)
| Class | Residual current | Use in PV context |
|---|---|---|
| AC (Type A) | 30 mA / 100 mA / 300 mA | general AC circuits; 300 mA acceptable for inverter feed-in where required |
| A (Type A) | 30 mA / 300 mA | detects pulsating DC — required where inverter output can contain DC components (some older inverters) |
| **B / B+** | 30 mA | **mandatory for EV wallbox circuits** (smooth DC fault detection) |
| F | 30 mA / 300 mA | PV-specific RCD (detects PV DC fault currents) — used at the inverter AC side when an RCD is installed there |

### Residual current limit checks
- Socket circuits (incl. wallbox): **30 mA** — hard requirement.
- Inverter feed-in (if RCD installed): **300 mA** typical, with an upstream
  conventional protection (MCB/fuse) providing the backup.

## Properties SolarPlanner should persist for this standard

| Item | Property | Required? | Why (which check) |
|---|---|---|---|
| Wallbox (inventory) | `rcdType` ('A' / 'B') — *missing today* | **required** for the wallbox warning feature | Wallbox circuits need Type B; warn if a project uses a wallbox without noting a Type B RCD. Add `text` column, default 'B'. |
| Wallbox (inventory) | rated current / `powerKw` + phases → compute charging current | **required** (derivable) | Charging current `I = P / U` must be ≤ circuit MCB rating and RCD rated current. |
| Inverter (inventory) | `hasRcd` / recommended RCD class at AC side — *missing* | optional | To drive the "RCD at coupling device" recommendation. Add nullable text (`'A'`/`F'`/null). |
| Project (site) | `hasRcdAtCouplingDevice` (bool), RCD class — *missing* | recommended | To state whether the feed-in side is protected and with which class. Add to `Projects` or a new electrical-installation table. |
| Project (site) | grid connection: `gridPhases` (1/3), `maxFeedInKw`, existing main switch rating — *missing* | **required** for feed-in checks (see VDE-AR-N 4105) | Inverter output vs connection point. |

## Formulas to validate in the app

- Wallbox charging current: `I_charge = P_kW · 1000 / U` (single-phase,
  `U = 230 V`) or `/ (√3 · 400)` for three-phase. Check
  `I_charge ≤ I_N(MCB) ≤ I_Z(cable)` (cross-ref VDE 0100-443) and
  `I_charge ≤ I_N(RCD)`.
- Inverter feed-in current: same formula as the AC MCB sizing in
  `vde-0100-443.md`. If an RCD is placed at the coupling device, its rated
  current must be ≥ inverter output current.

## Warning triggers to implement (VDE 0100-534)

- ⚠️ Wallbox present in project but no Type B RCD noted → "Wallbox-Kreis
  erfordert FI-Schutzschalter Typ B (30 mA)".
- ⚠️ Inverter feed-in current exceeds the selected coupling-device RCD/MCB
  rating → suggest next standard size.
- ⚠️ Single-phase inverter on a three-phase grid (or vice versa) → phase
  mismatch at the connection point.
- ⚠️ `maxFeedInKw` (grid operator limit) < total inverter AC power →
  oversizing vs grid agreement; suggest derating or a storage buffer.
