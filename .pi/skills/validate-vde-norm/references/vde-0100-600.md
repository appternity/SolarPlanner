# DIN VDE 0100-600 — Earthing arrangements & equipotential bonding

German adoption of IEC 60364-5-54. Governs how the **protective earthing (PE)**
and **equipotential bonding** are realized: PE conductor sizing, connection of
module frames and inverter to the equipotential, and use of natural conductors.

For SolarPlanner this standard is mostly about **checking that earthing is
planned and sized correctly**, not about complex computation.

## 1. Core requirements (§542 / §543)

- Every **exposed conductive part** (module frame, inverter housing, metal
  mounting rails) must be connected to the **main equipotential** (Haupt-
  Potentialausgleich) via a protective conductor.
- In PV **Class B** systems (see VDE 0100-712), module frames are exposed
  conductive parts → **must be earthed** (unless Class II / double-insulated).
- The PE connection must have a **low impedance** and be mechanically durable;
  the cross-section follows the table below.

## 2. PE conductor minimum cross-section (Tabelle §543)

For **automatic disconnection** by overcurrent protection, the PE conductor
cross-section `S_PE` must satisfy (simplified planning rule):

```
If S_phase ≤ 16 mm²:        S_PE ≥ S_phase          (same size as phase)
If 16 < S_phase ≤ 35 mm²:   S_PE ≥ 16 mm²
If S_phase > 35 mm²:        S_PE ≥ S_phase / 2      (thermal stability)
```

- For PV **DC strings**, the "PE" is typically a dedicated bonding conductor or
  the mounting structure itself (if it qualifies as a natural protective
  conductor — continuous, low-resistance metal path). Flag: "verify the mounting
  structure provides a continuous equipotential; otherwise add a dedicated PE".
- **Natural conductors** (metal roof structure, rails) may be used as the PE
  path **only if** they are continuous and not intended to be removed — a
  planning note for the electrician, especially on flat roofs with ballasted
  (non-bolted) mounting where continuity is questionable.

## 3. Equipotential bonding of the installation (§542)

- The **main equipotential bar** (Haupt-Potenzialausgleich, HPA) at the
  distribution board must connect: PE main conductor, inverter frame, battery
  system (if present), wallbox, and any metallic services entering the building.
- PV-specific: the inverter's PE terminal connects to the HPA; module frames
  connect (via rails or a dedicated conductor) back to the inverter PE / HPA.
- **Battery storage:** the battery system frame must also be part of the
  equipotential; for hybrid inverters with an integrated battery, this is one
  PE connection.

## Properties SolarPlanner should persist for this standard

| Item | Property | Required? | Why (which check) |
|---|---|---|---|
| Module (inventory) | `frameClass` ('I' / 'II') — *missing* (also in 0100-712) | recommended | Class I → frame must be earthed; Class II (double insulated) → no earthing needed. Drives the earthing warning. Add nullable text to `SolarModules`. |
| Inverter (inventory) | has PE terminal / is Class I equipment — *missing* | recommended | Inverters are effectively always earthed; a flag lets the tool state "inverter frame → HPA". Add bool, default true. |
| Battery (inventory) | `hasFrame` / needs earthing — *missing* | optional | Most battery systems have a metal frame → earth it. Add bool, default true. |
| Project (site) | `hasMainEquipotential` (bool), PE conductor cross-section used, mounting structure continuity — *missing* | **required** to state earthing compliance | Add to `Projects` or a new electrical table: bool + optional text note. Without it, the tool can only *recommend* earthing, not confirm it. |
| Project (site) | roof mounting type: bolted vs ballasted — *missing* | recommended | Ballasted (flat roof, no bolts) → natural-conductor path questionable; flag for dedicated PE. The app already has `flatAttikaHeightCm` etc.; add a bool `isBoltedMounting`. |

## Formulas to validate in the app

- PE cross-section check (above) — implement as a simple table lookup given the
  phase/DC cable cross-section. Low complexity, high value for completeness.
- No complex computation otherwise; this standard is about **presence and
  connection**, which the app can only check if the project-level earthing data
  is persisted.

## Warning triggers to implement (VDE 0100-600)

- ⚠️ Class I modules present but project has no `hasMainEquipotential` /
  earthing noted → "Modulrahmen (Klasse I) müssen mit dem Potenzialausgleich
  verbunden werden — Erdung im Projekt nicht erfasst".
- ⚠️ Flat roof with ballasted mounting (not bolted) → "Natürlicher
  Schutzleiter über die Aufständerung nicht sicher — dedizierten PE-Leiter
  vorsehen".
- ⚠️ Battery system present but no frame earthing noted → "Batteriesystem muss
  in den Potenzialausgleich einbezogen werden".
- ⚠️ PE cross-section below the table minimum for the chosen cable size →
  suggest next standard size.
