# DIN VDE 0100-443 — Protection against overcurrent

German adoption of IEC 60364-4-43. Governs selection and coordination of
protective devices (fuses, MCBs) so that every conductor is protected against
both **overload** (thermal damage from sustained current) and **short circuit**.

## 1. The fundamental sizing rule (§430 / §542)

For every circuit, one of these must hold:

```
I_B ≤ I_N ≤ I_Z          (1)  device rated at or below conductor capacity
I_B < I_N ≤ I_Z          (2)  next standard rating above load current allowed
I_B < I_N and I₂ ≤ k·I_Z (3)  device must trip before conductor is damaged
```

- `I_B` — maximum continuous load current of the circuit (A)
- `I_N` — rated current / nominal rating of the protective device (fuse: gG/aM
  rating; MCB: In)
- `I_Z` — allowable current-carrying capacity of the conductor (A), **after**
  installation-method and temperature correction factors
- `I₂` — let-through current of the device at its tripping condition (from fuse
  / MCB characteristic curves)

**For PV DC strings:** `I_B` is the string operating current (≈ `Imp`, or
`1.25 · Imp` for continuous PV load per IEC 62548 / VDE-AR-N 4105), and the
**string fuse** is sized to `I_sc` of one string (see below), NOT to `I_B`.

## 2. Conductor capacity I_Z — correction factors (Tabelle 4 / Anlage)

`I_Z = I_tab · f_installation · f_temperature · f_grouping`

- `f_installation`: installation method (e.g. cable in conduit on wall vs
  direct lay) — for PV: DC cables often in trunking (Kabelkanal) or conduit
  on the roof.
- `f_temperature`: ambient temperature correction — **critical for PV**: DC
  cables on a hot roof see far more than the reference 30 °C. At 40–50 °C
  ambient on the roof, copper cable capacity drops ~10–20 %.
- `f_grouping`: derating when cables are bundled.

**Planning hint for SolarPlanner:** store the DC cable cross-section and
installation method per string (or as a project default) so `I_Z` can be
computed. Without it, only the fuse check is possible — flag that as a missing
calculation.

## 3. Short-circuit protection (§431)

The device must clear a fault within **5 s** (or instantaneously for
≤ 0.1 s) and the conductor must withstand the fault energy:

```
I_k² · t ≤ k_sc² · S²     (conductor withstand, I²t criterion)
```

- `I_k` — prospective short-circuit current at the fault point (A)
- `t` — clearing time of the device at `I_k` (s, from characteristic)
- `S` — conductor cross-section (mm²), `k_sc` ≈ 143 for copper in most
  installation methods

For PV DC circuits the prospective fault current is limited by the source
(strings), so this check usually passes easily — but it must still be stated as
done. The **string fuse** is the short-circuit protection for downstream cable.

## 4. PV-specific application (with VDE-AR-N 4105 / VDE 0100-712)

### String fuse (DC, per string at the combiner/inverter input)
- Rating: **next standard fuse rating above `I_sc` of one string** (standard
  values e.g. 10, 15, 20, 25, 35 A for DC fuses).
- NEVER size to the parallel sum of strings — a fuse must pass one string's
  `I_sc` but limit fault current to the cable.
- Check: `I_N(fuse) ≥ I_sc(string)` and `I_Z(cable) ≤ I_N(fuse) · (safety factor
  per fuse characteristic)` — i.e. the cable must be protected by the fuse:
  `I_N(fuse) ≤ I_Z(cable)` (rule 1/2 above).

### Inverter AC output MCB
- `I_N(MCB) ≥ I_out,rated(inverter)` where
  `I_out = P_rated / (U · cos φ)`, typically `cos φ ≈ 1` for PV inverters.
- Single-phase: `I_out = P_rated / 230 V`; three-phase:
  `I_out = P_rated / (√3 · 400 V)`.
- MCB curve: **C** for inverter feed-in (inrush from the DC side is not an
  issue on AC, but C gives margin); **D** only if the installer specifies.

### Coordination (Stufung)
- Upstream main switch / MCB must coordinate with the inverter output MCB:
  selectivity so a fault on one PV system does not trip the whole house.
- Check: upstream device's let-through at fault current > downstream clearing,
  or time grading ≥ 0.2 s between levels (planning-level approximation).

## Formulas to validate in the app

- `autoAssignStrings()` currently checks only
  `voc_string ≤ maxInputVoltage` and per-string `isc ≤ maxShortCircuitCurrentPerMpp`.
  It does **not** check: min start-up voltage at hot conditions, fuse sizing, or
  cable `I_Z`. See `vde-ar-n-4105.md` for the full string-voltage window.
- Any AC MCB sizing feature must use `I_out = P_rated / (U · cos φ)` with the
  correct phase count — a single-phase inverter on a three-phase grid must NOT be
  divided by √3.

## Warning triggers to implement (VDE 0100-443)

- ⚠️ `I_sc(string)` exceeds the next standard fuse rating available for the
  selected cable → suggest larger cable or fewer modules per string.
- ⚠️ `I_Z(cable, corrected) < I_N(fuse)` → cable not protected by fuse.
- ⚠️ Inverter AC output current exceeds the selected MCB rating → suggest next
  standard MCB size.
- ⚠️ DC cable on roof without temperature derating applied → planning error,
  flag that `I_Z` is overstated.
